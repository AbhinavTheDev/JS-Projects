# For Adding New Project

- Go To `data.js` File and add project info in it.

- Add following info about project
```
 * ID of the project
 * Name of the project
 * Link (Live Hosted Link (if any)) of the project
 * Image (or Screenshot) of the project
 * Detail (Short Brief) of the project
 * Tech Stack Tags of the project

```

That's it!!!
